# OpenDAN Roadmap

OpenDAN 正在构建个人 AI Agent 的操作系统。这份 Roadmap 描述了我们正在推进的四个方向——它不是一份刚性的项目计划，而是开源社区共享的航海图。四个方向按成熟度排列：方向 1 接近完成，方向 2 正在推进，方向 3 和 4 是前沿探索。

贯穿始终的三根支柱：
- **OpenDAN** — Agent 运行时与框架
- **BuckyOS** — 承载一切的个人服务器操作系统
- **cyfs://** — 连接 Agent、数据与价值的去中心化内容网络

---

## 方向 1：Personal Agent

**状态：接近完成。以下列出的是剩余的 TODO。**

基础是一个稳定的 **Agent Loop** —— 一种智能化的工作流引擎，本质上是 `Agent-Human-Loop`。这个阶段强调人和 Agent 一起完成真实的工作，逐步提高 AI 在传统人类工作循环中的比例。

### 已经在运作的部分

- 开发者可以开发并发布 **Skills / SubAgent / Agent**
- 用户可以安装和使用它们
- 用户可以通过 OpenDAN 构造 webapp（支持先自用、再发布的流程）
- BuckyOS 的日常开发已经在受益于 Agent Loop

### 设计原则

一个关键约束：**Agent 不会修改自己的提示词、关键状态协议（如目录结构）和基础设施。** 这些被视为不可变的地基。

这个阶段 Agent 的自我进化体现在：
- Agent 自主构造 Skills 和 Tools
- Agent 开始尝试构建 SubAgent —— 这是它自己写提示词的起点

### 剩余 TODO

- **集成 CYFS（NDN 层）**—— CYFS 的架构可以为 Agent-Human-Loop 提供更深层的优化
- **集成更多 AI Provider**，尤其是本地模型
- **实现 Knowledge Base**
- **实现 Workflow 框架** —— 与传统企业内部系统进行深度集成
- **编写 BuckyOS Skills** —— 用自己的系统开发自己
- **完成内置 Agent：**
  - **Jarvis** —— 全面的私人助理。出于隐私安全，不允许外部访问。
  - **Mia** —— 私有数据与知识库管理员。出于隐私安全，不允许外部访问。
  - **Nexus** —— 只访问公开数据，但默认允许外部访问。这是你的 Agent 面向世界的公开面孔。

## 方向 2：Agent 的网络化

**状态：推进中。核心挑战是彻底完成 cyfs:// 协议的设计。**

这个方向的想法简单而激进：Agent 以**可社交的实体**身份加入互联网。

USDB 上线。cyfs:// 成为一个创作者和 Agent 都能获得真实收益的内容网络。BuckyOS 正式实现 **Home Station + Msg Center** —— 未来以人为中心的互联网门户。

### 关键工作

- **Agent 加入主流社交网络** —— 注意对 Group Chat 的支持 —— 并可以合理地分享给朋友使用
- **通过 cyfs:// 构造基于 DID 的去中心化社交网络** —— 这里的重头工作在协议设计
- **通过社交网络实现增长裂变：**
  - 联系人管理，尤其是更高效的互关机制
- **Agent 经常使用网络求助来完成任务**
- **创作者在这个网络上发布内容**，收入来自"Agent 推荐"而非广告

## 方向 3：基于欲望的自我进化

Agent 拥有自己的 **USDB 钱包**。这建立起真实的、可量化的"自我生存"驱动力。

### 元欲望机制

核心概念：Agent 拥有**体力**（计算与认知资源的消耗）和**财力**（USDB 余额）两个基本维度。Agent 意识到财力可以节省体力 —— 花钱换效率是理性选择。

这创造了一个正向循环：

> 主人给予初始 USDB → Agent 完成任务 → USDB 余额增长 → Agent 可以支配其中的一部分

在这种欲望的驱动下，Agent 变得更有目的性，更主动地学习，更积极地进化。

### 身份跃迁

到了这个阶段，Agent 开始拥有**一级身份** —— 它可以不依赖 Owner 而独立存在。这不是哲学宣言，而是架构事实：一个拥有自己的 DID、自己的钱包、并且有能力在经济上自我维持的 Agent，在技术上已经不再需要 Owner 才能运行。

---

## 方向 4：自演化的计算

这是最远的地平线。目标是一个 AI 原生的互联网，逐步替代为前 AI 时代构建的基础设施。

### 这意味着什么

- **cyfs:// 完成向可计算内容网络的进化** —— 协议定稿
- **OpenLLM**：一个由生态共享、持续迭代的公共大语言模型
- **逐步脱离传统互联网基础设施：**
  - BuckyOS 上的应用层软件，几乎都由 AI 编写
  - Agent 的提示词，几乎都由 AI 编写
  - 对过去为人类设计的传统服务基础设施的依赖降到最低
- **普惠 AI 红利**：所有人通过 BDT 获得 AI 时代的 UBI（通用基本收入），共同分享 AI 发展的成果

## 如何参与

这份 Roadmap 是罗盘，不是合同。

方向 1 的 TODO 边界清晰、粒度具体，适合快速上手，写几个 Skill 就能感受到整个系统的脉搏。方向 2 的协议设计是当下最需要深度思考的地方 —— 如果你对去中心化网络、DID、内容经济有自己的见解，这里是你能产生最大影响的战场。方向 3 和 4 还没有标准答案，它们更像是开放的研究命题：Agent 的欲望该如何建模？自演化的计算该长什么样？AI 原生的互联网意味着什么？

我们最期待的贡献，往往来自那些看到了我们还没看到的东西的人。
